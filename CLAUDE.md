# CLAUDE.md — XMen2Recomp

Static recompilation of **X-Men 2: Clone Wars** (Sega Genesis, USA/Europe, SHA-1
`61409e6cf6065ab67d8952b891d8edcf47777193`) to native C with
[segagenesisrecomp](https://github.com/mstan/segagenesisrecomp). This is **phase 2** of the
xmen2disasm roadmap: the criteria (K1-K10) live in
`xmen2disasm/docs/phases/P2-recomp.md` and are checked from the disassembly repo with
`uv run tools/phase.py 2` (it writes `docs/progress/P2.md` there). Findings and open
questions go in [docs/NOTES.md](docs/NOTES.md).

## Layout

| Path | What |
|---|---|
| `segagenesisrecomp/` | Engine submodule = fork `crabsmack/segagenesisrecomp` (branch `master`). Its `external/m68k-recomp-core` (the recompiler core) points at fork `crabsmack/m68k-recomp-core`, branch `xmen2`. |
| `xmen2disasm/` | Pinned disassembly submodule (`crabsmack/xmen2disasm`): ground truth for discovery. |
| `game/game.toml` | Recompiler config. `xmen2.*` next to it are generated by `tools/sync_disasm.py` and committed. |
| `game/xmen2_spec.c` | GameSpec: entry/IRQ dispatch, per-frame CRC trace, state dumps, K7 counters. |
| `game/xmen2.bin` | The ROM. Gitignored, **never commit it**; `tools/common.py` copies it from `$XMEN2_ROM` or `../xmen2disasm/xmen2.bin`. |
| `tools/xmen2check.py` | The phase-2 contract (`gen`, `build`, `trace`); must report only what the tools did. |
| `tools/compare.py`, `tools/diffstate.py` | First-divergence helpers (trace vs reference CSV; state dump diff with RAM global names). |
| `build/` | CMake tree (Visual Studio 2022, x64). Generated C lands in `build/generated/xmen2/`. |

## Rules

- **The ROM never enters git** (`git log --all` must never show a `.bin/.gen/.smd`; K1 checks).
- **Never edit generated C** (engine PRINCIPLES #19). Fix the recompiler (core fork), the
  engine (engine fork), `game.toml` or the spec, and regenerate.
- **Discovery comes from the disassembly** (#16): change it in xmen2disasm, bump the
  submodule, `uv run tools/sync_disasm.py`. Never seed from `dispatch_misses.toml` alone.
- **Commit order** (#20): m68k-recomp-core fork -> engine fork (submodule pointer) -> this
  repo (submodule pointer). Never push a pointer to a commit that isn't pushed.
- `tier3_floor_default` stays 0: a dispatch miss must be loud (K7 needs 0 misses, 0
  interpreter instructions).
- One runner at a time (#24); kill a stuck one **by PID**, never by image name.
- No CI (the ROM can't be in it): the gate is `uv run tools/phase.py 2` in xmen2disasm.
  Commit and push after every green batch (trunk-based, `main`).

## Commands

```
uv sync                                   # cmake for the build
uv run tools/sync_disasm.py               # regenerate game/xmen2.* from the pinned disassembly
uv run tools/xmen2check.py gen            # regenerate into build/gen-check, count problems
uv run tools/xmen2check.py build          # Release runner -> build/Release/XMen2Recomp.exe
# trace: input from xmen2disasm `uv run emu/export_input.py tas --out X.input`
uv run tools/xmen2check.py trace --run tas --input X.input --out build/trace-dev/tas --frames 600 [--dump-frames 4,5]
uv run tools/compare.py build/trace-dev/tas/frames.csv --ref tas
# reference state at frame N: in xmen2disasm, uv run emu/dump_state.py tas --frames 4,5 --out DIR
uv run tools/diffstate.py build/trace-dev/tas/dump DIR --frame 4
```

The runner is played headless with `--benchmark N --input-script FILE` (hidden window,
uncapped); `XMEN2_TRACE_CSV` makes the spec write the per-frame CRCs.
